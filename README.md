# Dmitriy Shalberkin — Portfolio

Personal portfolio with WebGPU-powered page transitions.

## Setup

```bash
npm install
npm run dev
npm run build
```

Dev server runs at http://localhost:3000.

## Inspiration

Page transition technique based on [Building Persistent Page Transitions with WebGPU and Vanilla JavaScript](https://tympanus.net/codrops/2026/06/30/building-persistent-page-transitions-with-webgpu-and-vanilla-javascript/) by Ben Paine (Codrops).
